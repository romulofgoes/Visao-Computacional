# Exercícios Práticos de Visão Computacional
Exercícios de Visão Computacional, disciplina da pós-graduação da Universidade Federal Fluminense(UFF), ministrada pelo Prof. Dr. Leandro A.F. Fernandes.

## Modulo 3

### Equalizador de Histograma

* Permite aumentar o contraste de cores numa escala de 256 níveis para imagens de um canal de cor.

### Filtro de Mediana

* A função recebe uma imagem de um canal de cor e retorna uma nova imagem que retira sinais de valores discrepantes na imagem.
* Exemplo disponível na pasta para o erro do tipo "sal e pimenta"
